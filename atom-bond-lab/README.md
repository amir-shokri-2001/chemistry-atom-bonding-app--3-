# آزمایشگاه پیوند اتمی (نسخهٔ مستقل)

یک شبیه‌ساز شیمی برای ساخت اتم و پیوندهای شیمیایی — **کاملاً مستقل** از
پروژهٔ اصلی و بدون وابستگی به آن. کدها در یک فایل واحد `index.html` قرار دارند
و بدون هیچ مرحلهٔ ساخت (build) و بدون نصب وابستگی اجرا می‌شوند.

این پروژه در پوشهٔ جداگانه `atom-bond-lab` ساخته شده و هیچ تغییری در مخزن
گیت‌هاب یا پروژهٔ اصلی ایجاد نکرده است.

## امکانات
- جدول عناصر با جستجو و فیلتر بر اساس دسته (فلز / نافلز / شبه‌فلز / هالوژن / گاز نجیب)
- کشیدن عناصر به داخل بوم (با موس و لمسی)
- نمایش لایه‌های الکترونی و الکترون‌های در حال گردش
- تشخیص خودکار نوع پیوند بر اساس اختلاف الکترونگاتیوی:
  - **پیوند کووالانسی** (اختلاف < ۱٫۷): اشتراک الکترون
  - **پیوند یونی** (اختلاف ≥ ۱٫۷): انتقال الکترون از فلز به نافلز + بار الکتریکی
- پیوند زدن به دو روش: نزدیک کردن دو اتم یا کلیک روی دو اتم
- پنل اطلاعاتی اتم انتخاب‌شده، راهنمای پیوندها، اعلان‌ها
- ابزارها: نمایش/مخفی‌کردن الکترون‌ها، توقف/حرکت الکترون‌ها، بازگشت (Ctrl+Z)، پاک‌کردن
- حذف اتم انتخابی با دکمهٔ Delete (با بازگرداندن الکترون‌های اتم همسایه)

## اجرا
کافی است فایل را در مرورگر باز کنید:

```bash
# گزینهٔ ۱: فقط دوبار کلیک روی index.html
# گزینهٔ ۲: با یک سرور ساده
cd atom-bond-lab
python3 -m http.server 8080
# سپس به http://localhost:8080 بروید
```

یا در مرورگر، فایل `index.html` را مستقیم باز کنید.
